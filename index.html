Tentang saya

Saya senang bekerja di titik temu perangkat lunak dan perangkat keras. Saya merakit rangkaian dengan sensor dan mikrokontroler, lalu membangun tampilan web agar datanya mudah dibaca dan perangkatnya mudah dikendalikan.

Dengan menguasai dua sisi ini, saya bisa menyelesaikan satu produk dari ujung ke ujung tanpa harus menunggu tim lain, mulai dari pembacaan sensor sampai tombol di layar.
